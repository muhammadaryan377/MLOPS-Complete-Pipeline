# MLOPS Complete Pipeline

A production-style, end-to-end **spam classification** workflow using classical NLP and a Random Forest model, with data/model artifacts tracked via DVC.

## Overview

This repository implements a modular ML pipeline with separate stages for:

1. Data ingestion
2. Text preprocessing
3. Feature engineering (TF-IDF)
4. Model training
5. Model evaluation

The code is organized under `src/` and designed to be run stage-by-stage.

## Project Structure

```text
.

│   └── model_evalution.py

```

## Prerequisites

- Python 3.10+
- `pip`
- (Optional, recommended) virtual environment

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

If you want to pull DVC-tracked artifacts (data/models/metrics) from your configured remote:

```bash
dvc pull
```

## Running the Pipeline

Run each stage in order:

```bash
python src/data_ingestion.py
python src/data_preprocessing.py
python src/feature_engineering.py
python src/model_building.py
python src/model_evalution.py
```

## Artifacts

- `data/`: intermediate and processed datasets
- `models/`: trained model(s) and feature metadata
- `metrics/`: evaluation outputs (for example, JSON metrics)
- `logs/`: runtime logs generated by each stage

> The repository tracks major artifacts using DVC pointer files (`*.dvc`).

## Notes

- The evaluation script file is currently named `model_evalution.py` (spelling preserved for compatibility).
- Parameter configuration is expected via `params.yaml` (tracked through `params.yaml.dvc`).
